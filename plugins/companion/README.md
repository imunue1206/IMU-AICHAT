# @local/companion

一个有自己现实生活的陪伴者。她有自己的作息、住处、小金库、朋友和今天；
聊天只是她的生活漏到你这边的那部分。

跑在 DSH 宿主进程里，零依赖（只用 Node 内置模块），数据一个 JSON 文件。

## 装法

在 DSH 的插件管理里安装这个目录：

```
plugin_manager install_bundle  target = <这个目录的绝对路径>
```

安装是软链接，不是拷贝。所以**改这里的文件就是改运行中的插件**，
重载一次（管理里关再开）才生效。

## 数据

| 路径 | 内容 |
|---|---|
| `~/.dsh/companion/state.json` | 角色、对话、世界状态、画像 |
| `~/.dsh/companion/voice.md` | 你自己写的语气规则（可在面板「设定」里改） |
| `~/.dsh/companion/backups/` | 每天一份存档，留 7 天 |
| `~/.dsh/companion/avatar-*.{jpg,png,webp}` | 角色头像 |

`state.json` 里有个 `version`，是**数据结构版本**，和 `package.json` 的版本号不是一回事。
结构变了要写迁移，旧存档才读得出来。

## 功能地图

- **对话列表**：头像、最后一条、未读；点进去聊天，左上角返回。
- **她的世界**：「她的今天」看她在哪、在做什么、精力、余额、当天的事。
- **遇见一个人**：随机类型卡 + 六个社交定位，只给地点/时间/事件/外形，不给结论。
- **手动建档**：一句话 → 三个候选 → 确认 → 锁定；三天磨合期后可推翻，之后只能停用。
- **礼物**：有在途、有到达、有反应；她花钱会真扣小金库。
- **表情包 / emoji**：她偶尔自己发，你也能发。
- **关于我**：三档访谈（5 / 12 / AI 追问），生成一份可编辑的画像，影响每次对话和选人。
- **设定**：追加规则，或按 `[section: style|sample|relation]` 整段替换；可预览完整提示词。

## 已知边界

- 只有本地界面，没接微信 / QQ / 抖音。
- 物品是叙事物品：有价格、有库存、会被记住，但不发货、不付真钱。
- 没有语音、没有图片。
- 「遇见」没有频率上限。
- 语气规则是全局的，所有角色共用一份。
