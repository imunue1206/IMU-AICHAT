# 变更记录

版本号跟 `package.json` 走；tag 与它保持一致。

## v0.1.11 — 她会出门

- 她偶尔会出差、回老家或出去玩，1～3 天，每天约 7% 的概率触发。
- 出门期间：城市换成目的地，住酒店/老家/民宿，天气和距离跟着变，
  提示词里会写明「你不在家」。
- 名字旁边多了一行：平时是「杭州 · 距你 1124 公里」；出门时变成「出差 · 成都」。
- 「她的今天」底部有一个「让她出趟门 / 让她回来」，用来手动触发和验证。

数据结构：新增 `travel` 字段，可缺省（3）。

## v0.1.10 — 到达时间交给你定

- 三个渠道改成固定时间窗，用滑块选：
  - 外卖 7～17 分钟
  - 快递 6～36 小时
  - 网购 8～28 小时
- 越界会被夹回窗口内（选 1 分钟的外卖，实际按 7 分钟算）。
- **距离不再参与任何计算**。它现在只是一条展示信息：她的城市、离你多少公里，放在「她的今天」里。
- 夜间顺延的逻辑一并去掉，你选几点就是几点。

数据结构不变（3）。

## v0.1.9 — 外卖 / 快递 / 网购

- 送礼时选渠道：
  - **外卖**：在她附近点，20～60 分钟，**不受距离影响**（跨城也能给她点）
  - **快递**：从你这边寄，18 + 距离/80 小时，含夜里顺延
  - **网购**：下单寄给她，1.5～4 天，与距离无关
- 她送东西时按品类自动判断（吃的走外卖，其余走快递）。
- 到货提示词会区分「他给你点的外卖到了」和「他寄的东西到了」。
- 在途条只对快递显示距离。

数据结构：包裹新增 `kind` 取值 takeout/courier/online，旧值 express/parcel 自动映射（3）。

## v0.1.8 — 时令

- 生成人物时带上当前月份：衣服、作息、吃的东西要符合这个季节，而不是一年四季都穿卫衣。
- 提示词新增【时令】行，所有角色都知道现在是几月、什么季节。
- 时段切换时另有 16% 的概率冒出一条季节痕迹：秋天「天黑得越来越早」「路边在卖烤红薯」，
  冬天「手一直插在口袋里」，夏天「出门五分钟就一身汗」。
- 与天气事件同一条闸门：只影响 20 分钟内发生的时段，补算历史不追溯。

数据结构不变（3）。

## v0.1.7 — 天气进入她的一天

- 时段切换时，有 28% 的概率多一条被天气影响的日常：下雨忘带伞、降温加外套、热到一身汗、起雾看不清路。
- 只在**实时推进**时生效（事件发生在 20 分钟内）；重开补算历史时不追溯，不会给昨天编一场雨。
- 温和天气不加，避免噪音。

数据结构不变（3）。

## v0.1.6 — 天气与季节

- 新增 `weather.js`：优先向 Open-Meteo 取真实天气（无需 key），拿不到就按城市纬度和月份推算，
  并在当天保持稳定。
- 读取从不阻塞：缓存冷时返回空、后台预热，下一次消息就有了。
- 提示词新增【天气】：她的城市和你的城市的温度与天况，加上季节。
- 聊天头部状态栏会显示她那边的天气。
- 启动时预热所有角色的城市和你自己的城市。

注意：预报会把城市坐标发给 api.open-meteo.com；推算不联网。

## v0.1.5 — 距离决定时间

- 新增 `geo.js`：40 个城市的坐标 + 球面距离，零依赖。
- 「关于我」可以填你所在的城市；不知道就当异地（900 公里）。
- 送达时间由**距离**决定：同城才允许跑腿（20～60 分钟）；跨城一律走快递，时长按
  `18 + 距离/80` 小时浮动，1200 公里约 1.5 天。
- 提示词里多了「你们之间」：她知道自己和你在不在同一座城、隔多远，说话会带出来。
- 在途条会显示距离。

数据结构：新增 `root.user.city` 与包裹上的 `km` 字段，都是可缺省，旧存档兼容（3）。

## v0.1.4 — 送达时间有了依据

- 之前是均匀随机（她 15～45 分钟，你 30 分钟～6 小时），跟东西无关。
- 现在按品类分：奶茶/花/草莓这类走**跑腿**（20～60 分钟）；书、围巾、票、手套这类走**快递**（8 小时～3 天）。
- 快递不会在夜里送到：落在 22:00～08:00 的会顺延到次日 09:30。
- 在途条和物品页会标出「跑腿」还是「快递」，时间按分钟/小时/天显示。

数据结构不变（3）。

## v0.1.3 — 聊天记录可以往回翻了

- 修：打开对话只加载最近 60 条，往上滑不会继续加载，看起来像记录被截断（数据其实一直在）。
- 现在滚到顶部会自动往前加载 40 条，滚动位置保持不动。
- 服务端保留上限从 500 条提到 3000 条。
- 切换角色时，分页状态会重置，不会串。

数据结构不变（3）。

## v0.1.2 — 送礼不该惊动她

- 修：送礼后她会立刻回复，等于没收到就知道了。现在送出去只写进"在途"，不碰对话。
- 她只在东西真正到达时才知情，并对此反应。
- 到货触发的那条回复，提示词里改成「他寄的东西到了：🧤 一双手套」，不再把物品名当成一句话。

数据结构不变（3）。

## v0.1.1 — 物品有了账本

- 新增「物品」页：在途 + 往来记录，每件东西都能展开看当时的对话前后三句。
- 往来记录单独存在 `giftLog` 里，不随聊天窗口被裁剪，最多 200 件。
- 记录里标了方向（你送的 / 她送的）、价格、时间；点一下展开，再点收起。

数据结构：只新增字段，`state.version` 不变（3），旧存档直接兼容。

## v0.1.0 — 第一个固定版本

第一个"可以一直用下去"的状态。数据结构版本：`state.version = 3`。

### 她的世界
- 实时推进的作息、金钱、精力、事件流；关窗口继续跑，退出或睡眠后重开按分钟补算（上限 14 天）。
- 夜间"善意谎言"：起夜、还没睡、说过晚安、真睡了；迟到超过 30 分钟会丢掉场景说明，改成"刚看到"。
- 每天一份存档备份，留 7 天。

### 对话
- 私聊界面：气泡、时间分隔、正在输入、未读计数。
- **她可以不回**：模型判断，引擎只守三条（问句必回、不连续两次、第一次必回）。
- 表情包（20 个预设）与 emoji；贴纸单独成条。
- 物品：送出去会先"在路上"，到点才落卡片并触发她的反应；她送你也要等；她花钱真扣小金库，库存会进提示词。
- 提示词可编辑：追加规则，或整段替换 `style` / `sample` / `relation`；可预览她实际收到的全文。

### 角色
- 一键内置三人：林知夏、阿鲸、老周。
- 遇见：随机类型卡 + 六个社交定位（同频 / 深聊 / 兴趣 / 弱连接 / 互补 / 摩擦），
  只给地点、时间、事件、外形，不给结论；她先开口。
- 手动建档：描述 → 三个候选 → 确认 → 锁定。三天磨合期内可推翻或删除，之后只能停用。
- 人物管理：切换、停用 / 启用、删除（仅磨合期）。

### 关于我
- 三档访谈：5 题 / 12 题 / AI 追问（最多 18，够了会自己停）。
- 生成一份可编辑的画像，进入每次对话的提示词，并影响新人投放。
- 社交定位按覆盖轮转，覆盖完之后按"你在谁身上说的话多"加权，保留 20% 随机。

### 工程
- 零依赖，只用 Node 内置模块；单个 JSON 存档，原子写入。
- 存档结构带版本号，旧版本自动迁移。

### 已知问题
- 界面外观未做过视觉验收（开发环境拿不到屏幕录制权限）。
- 没有语音、图片、真实 IM 通道。
- 「遇见」没有冷却。
- 语气规则全局共用。
